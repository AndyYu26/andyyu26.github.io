# Andy Tu — Personal portfolio

A small, static developer portfolio with a project overview and practical notes on video background workflows.

**Website:** https://andyyu26.github.io/

**Featured project:** [BGChanger](https://bgchanger.video)

## Contents

- `index.html`: responsive portfolio, inline CSS, and direct links to the project documentation.
- `bgchanger-preview.png`: screenshot of the BGChanger homepage; its scene example is AI-generated.
- `favicon.svg`: initials mark.
- `.nojekyll`: serves the static files without Jekyll processing.

The application itself is hosted at https://bgchanger.video. This repository contains only the portfolio and project notes, with no application backend or account data.

## Publishing

In **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)`.

No framework, build command, third-party script, or external font is required.
